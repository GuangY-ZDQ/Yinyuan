# 测试素材

本目录的二进制素材**不随仓库分发**（体积与授权原因），需要用脚本生成：

```bash
bash tools/gen_assets.sh      # 需要 ffmpeg 与 python3
bash tools/run_all.sh
```

生成的内容包括：几种壳视频（`ffmpeg` 合成的 testsrc 视频，非版权素材）、各类 ZIP（store / 多条目 / 空包 / 注释 / ZIP64 / 截断 / 非 ZIP 等）。

以下素材无法由脚本生成，需要自行准备才能覆盖对应用例：

| 素材 | 用途 |
|---|---|
| 真实的高码率 1080p 视频（如 Big Buck Bunny） | 验证大体积、高码率壳视频 |
| `moov` 位于文件尾部的视频 | 验证盒子顺序不影响合成 |
| 尾部带 `size=0` 盒的视频 | 验证“盒链延伸到文件末尾”的边界 |
| 加密 ZIP（7-Zip 或 `zip -P` 生成） | 验证加密包只搬运不解密 |
| 7-Zip / WinRAR 原生分卷 | 验证分卷格式识别与报错文案 |

`docs/测试报告.md` 记录了完整素材清单与每一类用例的结果。
