# 构建说明

## 目录结构

```
隐渊_源码/
├── src/
│   ├── core.h            引擎接口（core_build / core_probe_mp4 / CoreCtx）
│   ├── core.c            ZIP 解析、偏移处理、MP4 盒扫描、写入与自校验（约 1300 行）
│   └── win/
│       ├── gui.c         Win32 自绘界面（无第三方 UI 库）
│       ├── app.rc        资源脚本：图标、清单、两套 MiSans 字体
│       ├── app.manifest  高 DPI / 视觉样式
│       ├── app.ico
│       ├── misans_regular.otf    （RCDATA 1011）
│       └── misans_semibold.otf   （RCDATA 1012）
├── tools/
│   ├── build.sh          交叉编译脚本（优先 mingw，缺失时回退 zig）
│   ├── run_all.sh        63 项回归

│   └── test_main.c       引擎单测入口
├── tests/assets/         测试素材（各类型 zip + 几个 mp4）

└── 界面预览*.png
```

## 依赖

**Windows 编译端**：MSYS2 里的 `mingw-w64-x86_64-gcc`（含 windres）。

**Linux 编译端**：`mingw-w64` 包；或只用一个 zig 0.14+ 二进制（自带 mingw 头文件与库）。

```bash
# Debian/Ubuntu
sudo apt install mingw-w64
```

## 编译

```bash
bash tools/build.sh
# 产物：dist/隐渊.exe
```

脚本会先判断有没有 `x86_64-w64-mingw32-gcc`：

- **有**：windres 编资源 → gcc 链接（`-municode -mwindows -static`）→ strip。
- **没有**：用 zg 交叉编译。此路径要求仓库里已存在 `build/app.res.o`（资源对象必须先用 mingw 的 windres 生成一次，因为 zig 不带 rc 编译器）。

手动等价命令：

```bash
x86_64-w64-mingw32-windres src/win/app.rc -O coff -I src/win -o build/app.res.o
x86_64-w64-mingw32-gcc -O2 -Isrc -municode -mwindows -static -static-libgcc \
    -o dist/隐渊.exe src/core.c src/win/gui.c build/app.res.o \
    -lcomctl32 -lcomdlg32 -lshell32 -luuid -lmsimg32
x86_64-w64-mingw32-strip dist/隐渊.exe
```

注意：用 zig 编出来的产物会依赖 UCRT（`api-ms-win-crt-*.dll`，Win10/11 自带）；mingw 编出来的是 msvcrt，兼容更老的系统。正式发布建议走 mingw。

## 关键实现点

- **偏移**：输出里 ZIP 的所有偏移（CD 条目 lho、EOCD 的 cd_off、ZIP64 记录与定位器）**保持相对值**，不改成绝对偏移。Bandizip 靠"EOCD 记录值 vs 实际位置"的差值推断前缀，差值被抹成 0 时会误判成"分卷，缺 .z01"。
- **随机填充**：free 盒头之后、ZIP 之前垫 64–256 字节随机数据，避免"视频尾巴紧跟一段 PK 签名"的结构特征，同时让每次产物哈希不同。
- **输入前置数据**：压缩包前面若有 N 字节额外数据，用 `EOCD 实际位置 - (cd_off + cd_size)` 反推补偿；ZIP64 定位器记的是相对偏移，签名不符时回退到"紧贴定位器之前 56 字节"再向前搜索。
- **外壳视频**：只做盒级扫描，不改动任何字节；尾部若是 `size=0` 的盒，自动改用纯追加模式。
